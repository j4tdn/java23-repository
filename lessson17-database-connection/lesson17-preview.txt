==== MVC ====

1. Model
--> Nơi chứa các đối tượng thao tác với cơ sở dữ liệu
--> Package: dao(data access object)

2. View
--> Có thể là file java hoặc fe file phụ thuộc vào ngôn ngữ đang sử dụng
--> Java: Render UI từ server trả về FE
--> FE  : Render ở phía client

3. Controller
--> Nơi chứa các đối tượng nhận request từ view
    - Truy vấn dữ liệu từ dao
    - Xử lý logic nếu có
    - Trả về view
--> Package: controller: nhận, trả request
-->        : service   : xử lý logic và lấy dữ liệu từ dao

Bài toán SELECT --> executeQuery
Bài toán UPDATE --> executeUpdate

==== Các bước làm ====
1. Viết câu truy vấn(bỏ qua bước chuẩn bị nếu đơn giản)
-- SELECT * FROM T04_ITEM_GROUP

2. Tạo method trong DAO tương ứng(tạo interface/class dao nếu chưa có)
-- Suy nghĩ xem method sẽ có
   + KDL trả về là gì
   + Tham số vào là gì
   + Đặt method đó ở dao interface/class nào cho hợp lý
     ... Tạo abstract method trong interface
	 ... Tạo implementation method trong class
	     Xử lý select/update 
		 
3. Tạo method trong SERVICE tương ứng(tạo interface/class service nếu chưa có)
-- Dạng 1: service chỉ có nhiệm vụ là lấy dữ liệu từ dao
   ... KDL trả về thường giống dao method đang gọi
-- Dạng 2: service có nhiệm vụ lấy dữ liệu từ dao(1 hoặc nhiều method) và xử lý logic
   ... KDL trả về suy nghĩ phù hợp với bài toán
==> Validate dữ liệu đầu vào

4. Gọi service từ view   


* sql injection: 
--> kỹ thật tấn công cơ bản vào hệ thống bằng cách truyền giá trị vào cho tham số của câu lệnh sql
    để làm cho câu lệnh sql luôn đúng và bỏ qua các điều kiện khác
--> thường xảy ra khi tham số truyền vào là chuỗi(varchar/string)
    
    VD1: login(username, password) --> inject value cho username || password để sql đúng --> trả về dữ liệu
        --> trả về đối tượng != null --> có tồn tại user --> login thành công
    
    VD2: SELECT * FROM T04_ITEM_GROUP WHERE C04_ITEM_GROUP_NAME = 'X' OR '1=1'

- sql không có tham số truyền vào: statement(sql hoàn chỉnh)
- sql có tham số truyền vào: preparedstatement(sql có thể truyền tham số set giá trị bởi jdbc)

- khác nhau giữa statement và preparedstatement
st = conn.createStatement();
rs = st.executeQuery(sql);

pst = conn.prepareStatement(sql);
